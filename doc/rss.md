# RSS
## Requirements
* Generate an RSS 2.0 feed at `/rss.xml`.
* Include all posts newest first.
* Include each post title, absolute URL, stable GUID, RFC 822 publication date, and full rendered HTML.
* Use `SITE_URL` for absolute URLs.
* Advertise the feed in every generated page.
* Link to the feed from the right side of the post-index header.
